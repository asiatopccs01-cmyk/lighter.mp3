# ASTRA 2027 发布检查记录

本轮检查通过，已整理为可以上传到静态网站托管平台的完整版本。

## 本轮更新

- 全站标题加粗、适度放大，增加浅立体阴影；正文和辅助说明一起提高字号、字重和对比度。
- 十二星座增加柔和光晕、连线流光、星点呼吸与轻微浮动。暂停动效及减少动态效果设置会停下相应动画。
- 调整手机、平板、横屏的星图与按钮间距，统一七个玻璃章节的标题位置。
- 修复手机内页返回图标隐藏的问题，扩大返回按钮；补上关闭内页后的焦点及页面标题恢复。
- 首屏打开个人阅读时保留首屏位置，避免返回时落到不稳定的位置。

## 检查范围

- 七个章节均可打开、返回、切换，并循环到年度总览。
- 十二星座有各自的年度阅读和爱情、事业、财富、身心内容。全部 144 份月份内容与显示对应。
- 月份按钮、上一月、下一月、首末边界、键盘箭头及 Home / End 正常。
- 星座入口、快速切换、记住及清除星座选择、浏览器前进后退、深层链接和刷新恢复正常。
- 音乐点击播放、暂停、音量调整、音量弹层的焦点、Esc 及点击外部关闭正常。
- 星图发光、流光、浮动、动效暂停、减少动态效果正常。
- 自动漫游推进、暂停、继续、结尾、手动滚动接管、结尾重播正常。
- 手机返回按钮可见；关闭阅读恢复相应焦点与页面标题。
- 首屏十二星座真实指针点击区域、主按钮、字体、七个玻璃卡片的标题与说明通过布局检查。
- 没有 WebGL 支持时，加载完成后仍可打开星座内容及月份导航。
- 完整导出文件已在浏览器加载并检查，不依赖外部 CSS、脚本、图片或音乐文件。
- 检查过程没有未处理的 JavaScript 异常。无法创建 WebGL 上下文的模拟场景会触发预期的降级提示。

## 屏幕尺寸

1440×1000、1024×768、768×1024、390×844、320×844、320×600、390×600、844×390、1440×600。

## 结果与实际范围

整站功能 76 项通过、发布检查 54 项通过、收尾检查 17 项通过，合计 147 项。

使用 Chromium 浏览器和桌面、平板、手机视口模拟进行功能与排版检查；3D 场景在软件渲染环境中验证。没有测量真实手机的帧率，也没有在真实 Safari / iOS 设备上验证。本报告记录发布前浏览器检查。本次发布采用仓库现有的 GitHub Pages，正式网址在部署完成后另外验证。

## 发布文件

- `index.html`：完整站点，全部样式、脚本、3D 库和媒体内嵌。
- `THREE-LICENSE.txt`：3D 库许可证，网页源码中也保留了一份。
- `README.md`：上传与站内路由说明。

上传时以 `index.html` 为网站入口；无需构建命令，也无需单独配置站内哈希路由。
